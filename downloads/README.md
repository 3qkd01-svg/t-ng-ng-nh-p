PA1DUAL FULL

Standalone package: pa1dual-full.zip. Extract the ZIP and run pa1dual/start-pa1dual.cmd.
Requires Node.js 22+ and Microsoft Edge or Google Chrome on a supported Windows system.
First start installs playwright-core 1.63.0 using npm ci from the included lockfile.

Schedule: 11, 13, 15, 17, 19, 21 Hanoi time. One browser tab, shared login.
First slot uses UI to learn an actual red ID; later slots may try one API request with previous actual ID +1.
ID +1 is a prediction. UI still follows the actual chat event and retains the permitted 500 ms second click.
Chat entry is 30 seconds before a slot; return home 5 minutes after a round finishes.
Bounded reconnect; media reduction preserves controls. Press Enter in the program window to stop.

Nine Chromium tests passed against an extracted bundle using a local mock server.
No real authenticated claim or Windows launcher was tested in Codex.
